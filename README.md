# Flashcards
## What is this?
This is a flashcard web-app to help you study. Cards are addable, editable and deletable. A flashcard will initially show a question, when you click on it, it'll flip and show the answer. To navigate the flashcards, you can use the arrow buttons on screen or use the mouse scroll to move one by one. To reach a specific card you can click the dots under the arrow buttons. The button 'Add card' will ask you for a question and an answer, and it'll generate a new flashcard to add to the deck. As you hover a card, two buttons will appear: One for editing and one for deleting. The deleting button will erase all data of the flashcard. The edit button works much like the add button, as you can change both the question and the answer.
## How did I do this?
I used HTML for building, CSS with a couple animations for style and vanilla JavaScript for the logic.
## How do I run this?
Since this is made with vanilla JavaScrip, just opening the index.html file should work if you have all files on the same dir.
